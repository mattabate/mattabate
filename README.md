I am an applied mathematician and AI researcher living in Jersey City, New Jersey. PhD in mixed-monotone systems and safe autonomy, Georgia Tech (advisors Sam Coogan and Eric Feron).

**Things I've built that other people use:**

- 🧵 [**wordlist**](https://github.com/mattabate/wordlist) — ~413,000 scored words for crossword construction, free to download, with the ML model that scored them.
- 🧩 [**sator**](https://github.com/mattabate/sator) — finds double word squares (every row and column a word) from the terminal.
- 🕸️ [**yc_scraper**](https://github.com/mattabate/yc_scraper) — a Beautiful Soup scraper for Y Combinator's site.
- 📰 [**journal_of_wordplay**](https://github.com/mattabate/journal_of_wordplay) — code behind pieces I've published in the Journal of Wordplay.
- 🧑‍💻 [**textql-puzzle**](https://github.com/mattabate/textql-puzzle) — a freelance puzzle-construction pipeline built for TextQL.
